# جت‌فیت | JetFit

اپلیکیشن فارسی و آفلاین دستیار هوشمند بدنسازی برای ورزشکاران و مربیان.

## وضعیت پروژه

این مخزن در حال توسعه است. معماری هدف:

- Kotlin
- Jetpack Compose و Material 3
- Clean Architecture و MVVM
- Room برای ذخیره‌سازی آفلاین
- Kotlin Serialization برای داده‌های JSON
- رابط کاربری فارسی و RTL

## نام محصول

- نام نمایشی: جت‌فیت
- نام فنی: JetFit
- Application ID: `com.jetfit.app`

## ساخت پروژه

پس از تکمیل اسکلت Android، اجرای build از طریق GitHub Actions و Gradle انجام خواهد شد.
